---
title: "Get Channel Details"
description: "Retrieve metadata for a specific WhatsApp channel from the local snapshot"
---

The `GET /api/v1/channels/:id` endpoint returns detailed metadata for a single WhatsApp channel from the cached snapshot.

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/channels/:id`
- **Required Scope**: `channels:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Path Parameters

<ParamField path="id" type="string" required>
  The WhatsApp channel JID (e.g. `120363049876543210@newsletter`).
</ParamField>

## Query Parameters

<ParamField query="account_id" type="string" required>
  The UUID of the WhatsApp account associated with the channel (e.g. `acc_01hy8z9q2w4e1234`).
</ParamField>

---

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.co.zw/api/v1/channels/120363049876543210@newsletter?account_id=acc_01hy8z9q2w4e1234" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const channelId = "120363049876543210@newsletter";
const accountId = "acc_01hy8z9q2w4e1234";

const response = await fetch(`https://wareply.co.zw/api/v1/channels/${channelId}?account_id=${accountId}`, {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

channel_id = "120363049876543210@newsletter"
account_id = "acc_01hy8z9q2w4e1234"

response = requests.get(
    f"https://wareply.co.zw/api/v1/channels/{channel_id}",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    },
    params={"account_id": account_id}
)

print(response.json())
```

</CodeGroup>

## Response Attributes

<ResponseField name="data" type="object" required>
  The channel metadata record.

  <Expandable title="data properties">
    <ResponseField name="id" type="string" required>
      The WhatsApp channel JID (`...@newsletter`).
    </ResponseField>
    <ResponseField name="name" type="string" required>
      Channel title.
    </ResponseField>
    <ResponseField name="description" type="string | null" required>
      Channel description.
    </ResponseField>
    <ResponseField name="role" type="string" required>
      Account relationship to the channel (`owner`, `admin`, or `subscriber`).
    </ResponseField>
    <ResponseField name="subscriberCount" type="integer | null" required>
      Total subscribers.
    </ResponseField>
  </Expandable>
</ResponseField>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `invalid_recipient` | Channel JID does not end in `@newsletter` or has invalid structure. |
| `400` | `invalid_request` | `account_id` query parameter is missing. |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `channels:read`. |
| `404` | `not_found` | Channel not found in the account snapshot. |

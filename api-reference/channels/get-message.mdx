---
title: "Get Channel Message"
description: "Retrieve the delivery status and metadata of a previously published channel message"
---

The `GET /api/v1/channels/messages/:id` endpoint retrieves the status and metadata of a channel update using its operation ID.

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/channels/messages/:id`
- **Required Scope**: `channels:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Path Parameters

<ParamField path="id" type="string" required>
  The unique channel message operation ID (e.g. `msg_ch_01hy8z9q2w4e1234`).
</ParamField>

---

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.co.zw/api/v1/channels/messages/msg_ch_01hy8z9q2w4e1234" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const messageId = "msg_ch_01hy8z9q2w4e1234";

const response = await fetch(`https://wareply.co.zw/api/v1/channels/messages/${messageId}`, {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

message_id = "msg_ch_01hy8z9q2w4e1234"

response = requests.get(
    f"https://wareply.co.zw/api/v1/channels/messages/{message_id}",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    }
)

print(response.json())
```

</CodeGroup>

## Response Attributes

<ResponseField name="data" type="object" required>
  The channel message record.

  <Expandable title="data properties">
    <ResponseField name="id" type="string" required>
      Stable channel message operation ID.
    </ResponseField>
    <ResponseField name="account_id" type="string" required>
      UUID of the WhatsApp account that published the message.
    </ResponseField>
    <ResponseField name="channel_id" type="string" required>
      Destination channel JID (`...@newsletter`).
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Payload type (`text` or `media`).
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Delivery status: `sent`, `accepted`, `queued`, `processing`, or `failed`.
    </ResponseField>
    <ResponseField name="external_message_id" type="string | null" required>
      Confirmed WhatsApp message ID.
    </ResponseField>
    <ResponseField name="error" type="string | null" required>
      Failure explanation, or `null`.
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      ISO 8601 creation timestamp.
    </ResponseField>
    <ResponseField name="sent_at" type="string | null" required>
      ISO 8601 network confirmation timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `invalid_request` | `:id` parameter is missing. |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `channels:read`. |
| `404` | `not_found` | Channel message not found in this workspace. |

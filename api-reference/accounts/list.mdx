---
title: "List Accounts"
description: "Discover active, connected WhatsApp business accounts accessible to your API key"
---

The `GET /api/v1/accounts` endpoint retrieves connected WhatsApp business accounts accessible to the authenticated API key within your tenant workspace.

This endpoint provides programmatic account discovery, allowing your services to resolve valid `account_id` identifiers, inspect phone numbers, and check connection statuses dynamically without manual dashboard lookup.

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/accounts`
- **Required Scope**: `accounts:read`
- **Plan Requirement**: Standard or higher (workspaces on the Free plan receive `403 plan_upgrade_required`)
- **Headers**:
  - `Authorization: Bearer wrp_live_<YOUR_API_KEY>` (required)
  - `X-Request-ID: <string>` (optional client correlation trace ID)

---

## Query Parameters

<ParamField query="status" type="string">
  Filter accounts by WhatsApp connection state (for example: `active`, `connecting`, `qr`, `disconnected`, `stopped`).
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive search query matching against the account `name`, `label`, or connected `phone_number`.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum number of account records to return per page (1 to 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of account records to skip for pagination.
</ParamField>

---

## Security & Tenancy Isolation

- **Workspace Boundary**: Accounts returned are strictly isolated to the tenant workspace bound to the API key. Cross-tenant accounts are never accessible.
- **API Key Account Restrictions**: If the authenticated API key was configured with an account whitelist (`account_restrictions`), this endpoint returns only the accounts permitted by that whitelist.
- **Safe Data Transfer Object (DTO)**: Internal worker connection details, auth session filesystem paths, PM2 process identifiers, and worker ports are scrubbed from the response to prevent information leakage.
- **Soft-Deleted Accounts**: Accounts marked as deleted are automatically excluded.

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.co.zw/api/v1/accounts?limit=10" \
  -H "Authorization: Bearer wrp_live_<YOUR_API_KEY>" \
  -H "Accept: application/json"
```

```javascript Node.js
const apiKey = "wrp_live_<YOUR_API_KEY>";

const response = await fetch("https://wareply.co.zw/api/v1/accounts?limit=10", {
  method: "GET",
  headers: {
    "Authorization": `Bearer ${apiKey}`,
    "Accept": "application/json"
  }
});

const result = await response.json();
console.log(result);
```

```python Python
import requests

api_key = "wrp_live_<YOUR_API_KEY>"

response = requests.get(
    "https://wareply.co.zw/api/v1/accounts",
    params={"limit": 10},
    headers={
        "Authorization": f"Bearer {api_key}",
        "Accept": "application/json"
    }
)

print(response.json())
```

## Response Attributes

<ResponseField name="data" type="object" required>
  The accounts list response payload.

  <Expandable title="data properties">
    <ResponseField name="accounts" type="array of objects" required>
      List of accessible WhatsApp accounts.

      <Expandable title="account properties">
        <ResponseField name="id" type="string" required>
          Unique WhatsApp account identifier UUID (e.g. `acc_01hy8z9q2w4e1234`). Use this value as the `account_id` parameter in messaging, broadcast, and template requests.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The display name assigned to the WhatsApp account.
        </ResponseField>
        <ResponseField name="label" type="string | null" required>
          Optional category label assigned to the account (e.g. `Support Line`, `Sales Desk`).
        </ResponseField>
        <ResponseField name="phone_number" type="string | null" required>
          **Canonical**. The connected WhatsApp phone number in international E.164 notation (e.g. `+263771234567`), or `null` if the account is pending connection.
        </ResponseField>
        <ResponseField name="phoneNumber" type="string | null" deprecated>
          **Deprecated compatibility alias** for `phone_number`.
        </ResponseField>
        <ResponseField name="status" type="string" required>
          The WhatsApp session connectivity status (e.g. `active`, `connecting`, `qr`, `disconnected`, `stopped`).
        </ResponseField>
        <ResponseField name="created_at" type="string" required>
          **Canonical**. ISO 8601 timestamp when the account was registered.
        </ResponseField>
        <ResponseField name="createdAt" type="string" deprecated>
          **Deprecated compatibility alias** for `created_at`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="total" type="integer" required>
      Total number of accessible accounts matching the applied query filters.
    </ResponseField>

    <ResponseField name="limit" type="integer" required>
      Page size applied to the query.
    </ResponseField>

    <ResponseField name="offset" type="integer" required>
      Pagination offset applied to the query.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
**Naming Convention**: `snake_case` properties (`phone_number`, `created_at`) are canonical. CamelCase properties (`phoneNumber`, `createdAt`) are deprecated compatibility aliases retained for older client integrations.
</Note>

## Error Handling

| Status | Code | Cause & Resolution |
| :--- | :--- | :--- |
| `401` | `unauthorized` | Missing, malformed, expired, or revoked API key. |
| `403` | `insufficient_scope` | API key lacks the `accounts:read` scope. Add the scope in Dashboard Settings. |
| `403` | `plan_upgrade_required` | Developer API access is not included in the Free tier. Upgrade to Standard or higher. |
| `403` | `forbidden` | Workspace is suspended. |
| `429` | `rate_limited` | Exceeded 60 requests per minute. Back off and inspect the `Retry-After` header. |
| `500` | `internal_error` | Unexpected server failure. Quote the `request_id` when contacting support. |

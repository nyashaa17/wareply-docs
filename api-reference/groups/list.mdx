---
title: "List Groups"
description: "Retrieve a paginated list of WhatsApp groups joined by the account from local cache"
---

The `GET /api/v1/groups` endpoint returns a paginated list of WhatsApp groups that the specified WhatsApp account is currently a participant of.

This endpoint is **cache-first**: it reads from the local database snapshot to deliver fast response times and prevent WhatsApp socket thrashing. To force a live synchronization with WhatsApp servers, call [POST /api/v1/groups/refresh](/api-reference/groups/refresh).

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/groups`
- **Required Scope**: `groups:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Query Parameters

<ParamField query="account_id" type="string" required>
  The UUID of the WhatsApp account whose groups you want to list (e.g. `acc_01hy8z9q2w4e1234`).
</ParamField>

<ParamField query="search" type="string">
  Optional search filter to match against group names (case-insensitive substring match).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum number of groups to return (between 1 and 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.co.zw/api/v1/groups?account_id=acc_01hy8z9q2w4e1234&limit=20" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const accountId = "acc_01hy8z9q2w4e1234";

const response = await fetch(`https://wareply.co.zw/api/v1/groups?account_id=${accountId}&limit=20`, {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://wareply.co.zw/api/v1/groups",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    },
    params={
        "account_id": "acc_01hy8z9q2w4e1234",
        "limit": 20
    }
)

print(response.json())
```

## Response Attributes

<ResponseField name="data" type="object" required>
  Envelope containing group items and pagination metadata.

  <Expandable title="data properties">
    <ResponseField name="groups" type="array of objects" required>
      List of groups matching the query.
      
      <Expandable title="group object properties">
        <ResponseField name="id" type="string" required>
          The canonical WhatsApp group JID (e.g. `120363041234567890@g.us`).
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The display name or subject of the group.
        </ResponseField>
        <ResponseField name="participant_count" type="integer" required>
          Total number of participants in the group.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="pagination" type="object" required>
      Pagination context.

      <Expandable title="pagination properties">
        <ResponseField name="limit" type="integer" required>
          Applied limit.
        </ResponseField>
        <ResponseField name="offset" type="integer" required>
          Applied offset.
        </ResponseField>
        <ResponseField name="total" type="integer" required>
          Total number of groups available for this account.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
**Backwards Compatibility**: The server also returns deprecated `participantCount` alongside canonical `participant_count`.
</Note>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `invalid_request` | `account_id` query parameter is missing. |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `groups:read`. |
| `403` | `account_access_denied` | Key whitelist does not include this `account_id`. |
| `404` | `not_found` | Account not found in this workspace. |

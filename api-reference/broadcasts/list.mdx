---
title: "List Broadcasts"
description: "Query and filter broadcast campaigns in your workspace"
---

The `GET /api/v1/broadcasts` endpoint returns a paginated list of broadcast campaigns created in your workspace, with optional status and account filtering.

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/broadcasts`
- **Required Scope**: `broadcasts:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Query Parameters

<ParamField query="account_id" type="string">
  Filter campaigns by WhatsApp account UUID.
</ParamField>

<ParamField query="status" type="string">
  Filter by campaign lifecycle status: `queued`, `processing`, `completed`, `failed`, `cancelled`, or `scheduled`.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of results per page (between 1 and 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip.
</ParamField>

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.indexai.co.zw/api/v1/broadcasts?status=processing&limit=10" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const response = await fetch("https://wareply.indexai.co.zw/api/v1/broadcasts?status=processing&limit=10", {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://wareply.indexai.co.zw/api/v1/broadcasts",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    },
    params={"status": "processing", "limit": 10}
)

print(response.json())
```

</CodeGroup>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `broadcasts:read`. |
| `403` | `account_access_denied` | Key whitelist does not allow access to the queried `account_id`. |

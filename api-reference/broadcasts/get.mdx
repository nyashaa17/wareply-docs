---
title: "Get Broadcast"
description: "Inspect the configuration, delivery counters, and execution status of a broadcast campaign"
---

The `GET /api/v1/broadcasts/:id` endpoint returns detailed metadata for a broadcast campaign, including live delivery counters (`sent_count`, `failed_count`, `skipped_count`).

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/broadcasts/:id`
- **Required Scope**: `broadcasts:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Path Parameters

<ParamField path="id" type="string" required>
  The unique broadcast ID (e.g. `bc_01hy8z9q2w4e1234`).
</ParamField>

---

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.co.zw/api/v1/broadcasts/bc_01hy8z9q2w4e1234" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const broadcastId = "bc_01hy8z9q2w4e1234";

const response = await fetch(`https://wareply.co.zw/api/v1/broadcasts/${broadcastId}`, {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

broadcast_id = "bc_01hy8z9q2w4e1234"

response = requests.get(
    f"https://wareply.co.zw/api/v1/broadcasts/{broadcast_id}",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    }
)

print(response.json())
```

## Response Attributes

<ResponseField name="data" type="object" required>
  The broadcast campaign record.

  <Expandable title="data properties">
    <ResponseField name="id" type="string" required>
      Broadcast identifier (`bc_...`).
    </ResponseField>
    <ResponseField name="account_id" type="string" required>
      Sending WhatsApp account UUID.
    </ResponseField>
    <ResponseField name="name" type="string | null" required>
      Campaign title.
    </ResponseField>
    <ResponseField name="target_type" type="string" required>
      Target classification (`individual`, `group`, or `channel`).
    </ResponseField>
    <ResponseField name="type" type="string" required>
      Payload type (`text`, `media`, or `template`).
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Execution status: `queued`, `processing`, `completed`, `failed`, `cancelled`, or `scheduled`.
    </ResponseField>
    <ResponseField name="total_targets" type="integer" required>
      Total recipient target count.
    </ResponseField>
    <ResponseField name="sent_count" type="integer" required>
      Count of confirmed dispatched messages.
    </ResponseField>
    <ResponseField name="failed_count" type="integer" required>
      Count of failed recipient attempts.
    </ResponseField>
    <ResponseField name="skipped_count" type="integer" required>
      Count of recipients skipped due to cancellation or formatting.
    </ResponseField>
    <ResponseField name="delay_ms" type="integer" required>
      Delivery pacing delay between messages in milliseconds.
    </ResponseField>
    <ResponseField name="send_at" type="string | null" required>
      Scheduled ISO 8601 execution timestamp, or `null`.
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      Creation timestamp.
    </ResponseField>
    <ResponseField name="started_at" type="string | null" required>
      Timestamp when campaign execution started.
    </ResponseField>
    <ResponseField name="completed_at" type="string | null" required>
      Timestamp when campaign reached terminal completion or cancellation.
    </ResponseField>
  </Expandable>
</ResponseField>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `invalid_request` | Broadcast ID parameter missing. |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `broadcasts:read`. |
| `404` | `not_found` | Broadcast not found in this workspace. |

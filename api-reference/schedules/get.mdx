---
title: "Get Schedule"
description: "Inspect details and planned dispatch time of a scheduled broadcast campaign"
---

The `GET /api/v1/schedules/:id` endpoint returns metadata for a single scheduled broadcast campaign.

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/schedules/:id`
- **Required Scope**: `broadcasts:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Path Parameters

<ParamField path="id" type="string" required>
  The unique scheduled broadcast ID (e.g. `bc_01hy8z9q2w4e1234`).
</ParamField>

---

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.indexai.co.zw/api/v1/schedules/bc_01hy8z9q2w4e1234" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const scheduleId = "bc_01hy8z9q2w4e1234";

const response = await fetch(`https://wareply.indexai.co.zw/api/v1/schedules/${scheduleId}`, {
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

schedule_id = "bc_01hy8z9q2w4e1234"

response = requests.get(
    f"https://wareply.indexai.co.zw/api/v1/schedules/{schedule_id}",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    }
)

print(response.json())
```

</CodeGroup>

## Response Attributes

<ResponseField name="data" type="object" required>
  The schedule record.

  <Expandable title="data properties">
    <ResponseField name="id" type="string" required>
      Broadcast schedule ID.
    </ResponseField>
    <ResponseField name="account_id" type="string" required>
      Associated WhatsApp account UUID.
    </ResponseField>
    <ResponseField name="name" type="string | null" required>
      Campaign name.
    </ResponseField>
    <ResponseField name="target_type" type="string" required>
      Target classification (`individual`, `group`, or `channel`).
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Lifecycle status: `scheduled`.
    </ResponseField>
    <ResponseField name="total_targets" type="integer" required>
      Number of recipient targets.
    </ResponseField>
    <ResponseField name="send_at" type="string" required>
      ISO 8601 execution timestamp.
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      ISO 8601 creation timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `invalid_request` | Schedule ID parameter is missing. |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `broadcasts:read`. |
| `404` | `not_found` | Scheduled campaign not found in this workspace. |

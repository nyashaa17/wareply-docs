---
title: "Cancel Schedule"
description: "Cancel a scheduled broadcast and automatically refund 100% of reserved recipient quota"
---

The `DELETE /api/v1/schedules/:id` endpoint cancels a scheduled broadcast campaign before its execution time arrives.

Because no messages have been dispatched to the WhatsApp network yet, **100% of the reserved recipient quota** is immediately and atomically refunded back to your workspace balance.

### Authentication & Permissions

- **Method**: `DELETE`
- **Path**: `/api/v1/schedules/:id`
- **Required Scope**: `broadcasts:write`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Path Parameters

<ParamField path="id" type="string" required>
  The unique scheduled broadcast ID to cancel (e.g. `bc_01hy8z9q2w4e1234`).
</ParamField>

---

## Request Examples

<CodeGroup>

```bash cURL
curl -X DELETE "https://wareply.co.zw/api/v1/schedules/bc_01hy8z9q2w4e1234" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript Node.js
const scheduleId = "bc_01hy8z9q2w4e1234";

const response = await fetch(`https://wareply.co.zw/api/v1/schedules/${scheduleId}`, {
  method: "DELETE",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Accept": "application/json"
  }
});

const result = await response.json();
console.log(result);
```

```python Python
import requests

schedule_id = "bc_01hy8z9q2w4e1234"

response = requests.delete(
    f"https://wareply.co.zw/api/v1/schedules/{schedule_id}",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Accept": "application/json"
    }
)

print(response.json())
```

</CodeGroup>

## Response Attributes

<ResponseField name="data" type="object" required>
  Cancellation and quota refund confirmation envelope.

  <Expandable title="data properties">
    <ResponseField name="success" type="boolean" required>
      Indicates successful cancellation (`true`).
    </ResponseField>
    <ResponseField name="id" type="string" required>
      Cancelled schedule ID.
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Updated status: `cancelled`.
    </ResponseField>
    <ResponseField name="refunded_units" type="integer" required>
      The number of `broadcast_messages` quota units refunded (equal to 100% of the campaign's total targets).
    </ResponseField>
  </Expandable>
</ResponseField>

---

## Response Example (HTTP 200)

```json
{
  "data": {
    "success": true,
    "id": "bc_01hy8z9q2w4e1234",
    "status": "cancelled",
    "refunded_units": 500
  }
}
```

<Note>
**Backwards Compatibility**: The server also returns deprecated `refundedUnits` alongside canonical `refunded_units`.
</Note>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `400` | `invalid_request` | Schedule ID parameter is missing. |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `broadcasts:write`. |
| `404` | `not_found` | Scheduled campaign not found or not in `scheduled` state. |

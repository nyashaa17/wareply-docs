---
title: "List Schedules"
description: "Retrieve all scheduled broadcast campaigns pending future delivery"
---

The `GET /api/v1/schedules` endpoint returns all scheduled broadcast campaigns in your workspace that are awaiting their execution timestamp.

<Note>
**Creating Schedules**: There is no standalone `POST /schedules` endpoint. Scheduled messages are created through the [Create Broadcast](/api-reference/broadcasts/create) endpoint by including the `scheduled_for` parameter.
</Note>

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/schedules`
- **Required Scope**: `broadcasts:read`
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

---

## Query Parameters

<ParamField query="account_id" type="string">
  Optional filter by WhatsApp account UUID.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Maximum results per page (between 1 and 100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

<CodeGroup>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `insufficient_scope` | API key lacks `broadcasts:read`. |
| `403` | `account_access_denied` | Key whitelist forbids access to the queried `account_id`. |

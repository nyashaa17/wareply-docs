title: "Get Identity & Tenancy"
description: "Verify your API key, workspace tenancy, granted scopes, and commercial plan status"
---

The `GET /api/v1/me` endpoint allows developers to verify their credentials and inspect the authenticated workspace, granted scopes, account restrictions, and subscription tier.

This endpoint is safe to call during system health checks or startup sequences. It never exposes raw secrets, internal database topologies, or sensitive credentials.

### Authentication & Permissions

- **Method**: `GET`
- **Path**: `/api/v1/me`
- **Required Scope**: Any valid API key
- **Headers**:
  - `Authorization: Bearer YOUR_API_KEY` (required)
  - `X-Request-ID: <string>` (optional client trace ID)

## Request Examples

<CodeGroup>

```bash cURL
curl -X GET "https://wareply.co.zw/api/v1/me" \
  -H "Authorization: Bearer wrp_live_<YOUR_API_KEY>" \
  -H "Accept: application/json"
```

```javascript Node.js
const response = await fetch("https://wareply.co.zw/api/v1/me", {
  method: "GET",
  headers: {
    "Authorization": "Bearer wrp_live_<YOUR_API_KEY>",
    "Accept": "application/json"
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://wareply.co.zw/api/v1/me",
    headers={
        "Authorization": "Bearer wrp_live_<YOUR_API_KEY>",
        "Accept": "application/json"
    }
)

print(response.json())
```

</CodeGroup>

## Response Attributes

<ResponseField name="data" type="object" required>
  The top-level response envelope containing identity metadata.

  <Expandable title="data properties">
    <ResponseField name="api_key" type="object" required>
      Details of the authenticated API key.
      
      <Expandable title="api_key properties">
        <ResponseField name="id" type="string" required>
          The unique API key identifier.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          The friendly name assigned to the key during creation.
        </ResponseField>
        <ResponseField name="key_prefix" type="string" required>
          **Canonical**. The non-sensitive prefix of the key used for identification (e.g. `wrp_live_abcd`).
        </ResponseField>
        <ResponseField name="keyPrefix" type="string" deprecated>
          **Deprecated compatibility alias** for `key_prefix`.
        </ResponseField>
        <ResponseField name="scopes" type="array of strings" required>
          List of authorization scopes granted to this key.
        </ResponseField>
        <ResponseField name="account_restrictions" type="array of strings | null" required>
          **Canonical**. Whitelist of account UUIDs this key is permitted to access, or `null` if unrestricted.
        </ResponseField>
        <ResponseField name="accountRestrictions" type="array of strings | null" deprecated>
          **Deprecated compatibility alias** for `account_restrictions`.
        </ResponseField>
        <ResponseField name="created_at" type="string" required>
          **Canonical**. ISO 8601 timestamp when the key was created.
        </ResponseField>
        <ResponseField name="createdAt" type="string" deprecated>
          **Deprecated compatibility alias** for `created_at`.
        </ResponseField>
        <ResponseField name="expires_at" type="string | null" required>
          **Canonical**. ISO 8601 expiration timestamp, or `null` if the key does not expire.
        </ResponseField>
        <ResponseField name="expiresAt" type="string | null" deprecated>
          **Deprecated compatibility alias** for `expires_at`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="apiKey" type="object" deprecated>
      **Deprecated compatibility alias** for `api_key`.
    </ResponseField>

    <ResponseField name="workspace" type="object" required>
      The tenant workspace bound to this API key.
      
      <Expandable title="workspace properties">
        <ResponseField name="id" type="string" required>
          Unique workspace identifier.
        </ResponseField>
        <ResponseField name="name" type="string" required>
          Display name of the workspace.
        </ResponseField>
        <ResponseField name="slug" type="string" required>
          URL-safe workspace identifier.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="plan" type="object" required>
      Subscription plan metadata.

      <Expandable title="plan properties">
        <ResponseField name="id" type="string" required>
          Plan identifier (e.g. `standard`, `pro`, `enterprise`).
        </ResponseField>
        <ResponseField name="name" type="string" required>
          Display name of the subscription tier.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
**Backwards Compatibility**: The server also returns deprecated camelCase aliases (`apiKey`, `keyPrefix`, `accountRestrictions`, `createdAt`, `expiresAt`) alongside canonical `snake_case` properties. New clients should consume `api_key`.
</Note>

## Common Errors

| Status | Code | Description |
| :--- | :--- | :--- |
| `401` | `unauthorized` | Missing, invalid, or revoked API key. |
| `403` | `plan_upgrade_required` | Workspace does not have commercial Developer API access (`api_access`). |
| `403` | `forbidden` | Workspace is suspended. |
| `429` | `rate_limited` | Rate limit exceeded (60 req/min). |
